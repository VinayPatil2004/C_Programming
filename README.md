# C_Programming

Welcome to the **C_Programming** repository! This repository contains a collection of programs and solutions developed as part of the **Logic Building Batch - C**. 

The primary focus of these assignments is to build a strong foundation in programming logic, problem-solving, and core algorithmic concepts using the C language.

## 📌 Repository Structure

The project is structured into individual assignment folders inside the `Assignments/` directory. Each folder contains exactly 5 C source files, sequentially named from question 1 to 5.

## 🚀 Topics Covered

* **Basic Syntax & I/O:** Understanding data types, operators, and basic input/output mechanisms (`printf`, `scanf`).
* **Conditional Branching:** Mastering decision-making flows using `if`, `else if`, and `else` constructs.
* **Iterative Loops:** Implementing repetitive execution flows with `for`, `while`, and `do-while` loops.
* **Logic Building:** Developing optimized algorithms to handle edge cases and nested conditional requirements.

## 🛠️ Getting Started

### Prerequisites
To compile and run these programs locally, ensure you have a C compiler installed on your system:
* **Windows:** GCC via MinGW / w64devkit, or MSVC via Visual Studio.
* **Linux / macOS:** GCC or Clang.

### Running a Program
1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd C_Programming
   ```

2. **Navigate to the target assignment folder:**
   ```bash
   cd Assignments/Assignment_1
   ```

3. **Compile a specific source file:**
   ```bash
   gcc program1_1.c -o program1_1
   ```

4. **Execute the compiled binary:**
   * **Windows:** `program1_1.exe`
   * **Linux/macOS:** `./program1_1`
